# 📊 EGX33 Stock Tracker

تطبيق ويب لمتابعة مؤشر EGX33 في البورصة المصرية مع تحليلات متقدمة وأخبار السوق.

## ✨ المميزات

- 📈 **رسم بياني بالشموع اليابانية** - عرض احترافي لحركة المؤشر
- 📰 **الأخبار والتحليلات** - متابعة أسباب الارتفاع والانخفاض
- 💡 **نصائح استثمارية** - توصيات ذكية بالشراء أو البيع
- 🎨 **تصميم داكن احترافي** - واجهة عصرية مريحة للعين
- 📱 **متجاوب مع جميع الأجهزة** - يعمل على الموبايل والتابلت والكمبيوتر

## 🛠️ التقنيات المستخدمة

- **Next.js 16** - إطار عمل React الحديث
- **TypeScript** - للكتابة الآمنة والخالية من الأخطاء
- **Tailwind CSS** - تصميم سريع واحترافي
- **Lightweight Charts** - مكتبة الرسوم البيانية المتقدمة
- **Lucide React** - أيقونات عصرية وجميلة

## 🚀 التشغيل المحلي

```bash
# تثبيت المكتبات
npm install

# تشغيل السيرفر
npm run dev

# فتح المتصفح على
# http://localhost:3000
```

## 📦 النشر على Vercel

### الطريقة الأولى: من خلال الموقع (الأسهل)
1. ادخل على [vercel.com](https://vercel.com)
2. اضغط "New Project"
3. اربط حسابك مع GitHub
4. اختر المشروع egx33
5. اضغط Deploy!

### الطريقة الثانية: من خلال CLI
```bash
# تثبيت Vercel CLI
npm i -g vercel

# النشر
vercel

# النشر للإنتاج
vercel --prod
```
